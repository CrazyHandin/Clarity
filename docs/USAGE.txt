Clarity 使用说明
项目与最新版：https://github.com/CrazyHandin/Clarity

运行要求
Windows 10/11，.NET Framework 4.8 或更高版本。
安装版默认安装到 C:\Program Files\Clarity，需要管理员权限，支持升级及卸载。
点击“浏览”可使用 Windows 文件夹选择窗口找到桌面、下载和其他磁盘；桌面快捷方式可选。
便携版请完整解压后运行 Clarity.exe，保留同目录的 Clarity.exe.config 和 rules 文件夹。
Winapp2 规则独立存放在 rules\Winapp2.ini，程序使用前校验随附快照的完整性。
从 1.0.5 或更早版本升级到 1.0.6，请手动下载安装一次；此后在线更新支持新的软件包文件名。

主题、语言与管理员模式
标题栏最小化按钮旁的太阳／月亮可切换深浅色；常规设置支持深色、浅色及跟随 Windows，并自动保存。
“液态玻璃（Beta）”可在常规设置中开启或关闭，应用于主界面与更新弹窗。
磁盘空间条的彩色部分表示已占用空间，未填充部分表示剩余空间。
在“设置与备份 → 常规设置”选择简体中文或 English，自动保存并立即生效。
管理员模式位于同一页面，可在确认 Windows 提权请求后重新启动。
普通权限清理失败或没有删除权限时，软件会询问是否以管理员身份重启。
文件占用或安全软件拦截不一定能通过提权解决；重启后需手动扫描，不会自动继续删除。
在“设置与备份”右上角可打开“关于 Clarity”。
设置、关于与使用说明均在主窗口内切换。返回清理会保留扫描结果与勾选状态。
关于页显示当前版本、内部构建号及更新概括，并提供使用说明入口。
范围卡片的整个区域均可点击；扫描取消及设置保存等消息在窗口上部显示，两秒后自动消失。

开始清理
1. 打开软件不会自动扫描。选择模式后点击“开始扫描”。
2. 快速扫描为默认，仅扫描内置的一键清理规则，使用简洁清理。
3. 常规扫描包含应用发现、外部规则和未知缓存，可使用高级自选。
4. 查看容量、项目说明和风险后清理。选中风险项目时弹窗确认。
5. 清理结束可打开“查看未完成项目”，核对失败、跳过或取消项目的路径与原因；点击“完成”回到初始界面。
Clarity 不扫描 Windows 系统目录。Windows 磁盘清理仍是清理按钮旁的独立选项。
“系统垃圾 → 休眠文件”仅在高级模式自选，会通过 Windows 命令关闭休眠、快速启动及混合睡眠，不经过文件备份。需管理员权限并确认风险后执行；恢复需以管理员身份运行 powercfg /hibernate on。

备份与恢复
默认先备份，ClarityBackups 优先位于其他本地磁盘。
在“设置与备份 → 备份与恢复”可修改目录、打开备份位置或恢复。
恢复请选择对应批次的 files.csbackup，仅支持本机及本账户，不覆盖已有文件。
恢复校验成功后清除对应备份及已空的日期批次目录；冲突、失败或其他文件继续保留。
备份保存在 C 盘时，对应空间需要清除备份后才能释放。
卸载程序会保留设置及备份。

清理选择
简洁清理只处理符合条件的低风险项目。清理缓存可能需要重新下载或使首次加载变慢。
未知缓存、社区规则默认不选，仅供高级自选且始终先备份。
请核对风险说明。占用、无权限或扫描后变化的文件会跳过。
Windows 磁盘清理是默认关闭的独立选项，自动处理 C 盘并退出。
系统磁盘清理不经过 Clarity 备份，可能无法恢复。

规则更新
“设置与备份 → 规则管理”支持 Winapp2 INI、JSON 规则更新和离线导入。
Winapp2 与 JSON 可同时勾选启用，在单独卡片中管理 Winapp2，JSON 统一进入规则库管理。
“JSON 规则库”支持多选 Schema 1 / 2 JSON 文件的导入、启停、升级和回退，新包默认关闭。
可点击“只读预览”查看规则候选，不删除文件。文件名、年龄、大小条件须同时满足；重复文件只处理一次。
JSON 规则填写说明可在规则管理中直接打开。
更新不上传应用列表、路径或扫描结果，不会自动扫描或删除。

清理记录与软件更新
清理记录自动保存在软件目录的 Logs 文件夹；目录不可写时保存在当前用户设置目录的 Logs 中。
在“设置与备份 → 常规设置”点击“打开清理记录”直接打开最近一次记录，也可打开记录文件夹。
软件启动时检查 GitHub Release；发现新版本或内部构建时显示红点和带倒计时的顶部提示。
在关于页点击“检查软件更新”，更新卡片底部显示加载条；无更新或检查失败时在窗口顶部提示。
有更新时弹出小窗口，显示更新说明和“下载并更新”按钮。下载时显示进度、百分比和文件大小，可取消。
点击“本版更新内容”小按钮，可在弹窗中查看当前版本的更新概括。
软件更新验证发布者签名及 SHA-256。Program Files 安装使用按需更新服务，服务完成任务后退出。
桌面等当前账户可写的自定义安装目录，直接更新程序文件，无需重复管理员授权；不额外安装便携包中的 Markdown 文档，保留卸载入口、记录和备份。
目录不可写或 Program Files 的服务未就绪时，仍使用需要授权的安装器；手动运行安装包也需要管理员权限。
安装版自动升级后以原账户重新打开；文件更新失败时尝试恢复原文件。卸载会移除更新服务。
下载可取消，检查更新不自动扫描或清理；更新及安装可能需要联网与 Windows 权限确认。

English User Guide

Winapp2 and JSON can be enabled together in Rule management, with independent update preferences. The JSON rule library supports batch import of Schema 1 / 2 JSON files, individual toggles, upgrades and rollback; new packs start disabled. Read-only preview shows candidates without deletion. Filename, age and size conditions use AND logic, and overlapping candidate files count once.

To upgrade from 1.0.5 or earlier, download and install 1.0.6 manually once. Later online updates support the new package names.

Clarity
Project and latest release: https://github.com/CrazyHandin/Clarity

Requirements and installation
Windows 10/11 with .NET Framework 4.8 or later.
The installer defaults to C:\Program Files\Clarity and requires administrator permission.
Browse opens the Windows folder picker, with access to Desktop, Downloads, and other drives.
Upgrade and uninstall are supported; the desktop shortcut is optional.
For the portable edition, extract the complete package and keep Clarity.exe.config and the rules folder beside Clarity.exe.
The bundled Winapp2 snapshot is stored in rules\Winapp2.ini and its integrity is checked before use.

Language and administrator mode
Open Settings & Backups > General to choose Simplified Chinese or English.
Language changes are saved automatically and apply immediately.
Administrator mode is in the same section. Restart requires approval of the Windows UAC prompt.
When standard-permission cleanup fails or access is denied, Clarity offers an administrator restart.
Elevation may not resolve locked files or security software blocks. Restart does not resume deletion:
scan again manually and review the results before cleaning.
Open About Clarity from the top-right corner of Settings & Backups.
Settings, About, and help use the same window. Back to cleanup preserves scan results and selections.
About contains the version, internal build, update summary, and user guide.
Click anywhere on a scope card to select it. Scan cancellation and saved-setting messages appear at the top for two seconds.
Windows folder pickers and UAC prompts follow the Windows display language.

Start cleaning
1. Opening Clarity does not start a scan. Choose a mode and click Start scan.
2. Quick scan is the default and appears first. It checks built-in, one-click-eligible rules only.
3. Regular scan appears below Quick scan. It includes app discovery, external rules, and unknown caches.
4. Review sizes, explanations, and risks. Quick scan provides Simple cleanup; Regular scan also offers Advanced selection.
5. Risk selections require confirmation. Eligible low-risk one-click cleanup does not show a risk prompt.
6. Open View unfinished items to inspect selected failed, skipped or cancelled paths and reasons. Click Done to return to the initial screen.
Clarity excludes the Windows system directory. Windows Disk Cleanup remains a separate optional action.
The Sun/Moon button beside Minimize switches themes; General settings offers Dark, Light and Follow Windows, with saved preferences.
Liquid Glass (Beta) can be toggled in General settings and applies to the main interface and update dialogs.
The colored part of the disk bar represents used space; the unfilled part represents free space.
Advanced cleanup includes an optional System junk → Hibernation file action. It uses Windows powercfg to disable hibernation, Fast Startup and hybrid sleep without a file backup. Administrator privileges and risk confirmation are required. To restore hibernation, run powercfg /hibernate on as administrator.

Backups and restoration
Backup-first cleanup is the default. ClarityBackups preferably uses another local drive.
Use Settings & Backups > Backup & Restore to change or open the backup location and restore files.
Select a batch's files.csbackup index. Restoration requires the same computer and Windows account.
Existing files are preserved. Verified restored copies and empty dated batch folders are removed from the backup;
conflicts and failed items remain available for later restoration.
Backups stored on C: must be removed before their corresponding space is freed.
Registry backup restoration and its folder shortcut are in the same section.
Uninstall preserves application preferences and backups.

Cleanup choices and risks
Simple cleanup processes eligible low-risk items. Removed caches may need downloading or rebuilding.
Unknown caches and community rules are unchecked by default, Advanced-only, and always backed up.
Review risk explanations. In-use, inaccessible, linked, or changed files are skipped.
Windows Disk Cleanup is a separate, unchecked option. It processes C: automatically and exits when finished.
Its deletions bypass Clarity backups and may be irreversible.
If security software reports a threat, pause installation or use and request vendor review.
The interface changes do not establish that earlier Trojan/Ursnif detections have been resolved.

Rule updates and privacy
Settings & Backups > Rule Management supports Winapp2 INI, JSON updates, and offline imports.
Rule-source changes apply after Save rule settings. Portable folder changes are saved automatically.
The JSON authoring guide is available directly from Rule Management.
Updates download rules without uploading app inventories, paths, or scan results.
Updating rules does not automatically scan or delete files.

Cleanup history and software updates
Cleanup history is saved automatically in the application's Logs folder, or the current user's settings folder if unwritable.
Settings & Backups > General > Open cleanup history opens the most recent record. A folder shortcut is also available.
Clarity checks GitHub Releases on startup. A new version or internal build adds red badges and a clickable countdown notification.
Click Check for software updates in About. A loading bar appears along the bottom of the update card; no-update and error results use top notifications.
Available updates open in a small window with notes and a Download and update button. Downloads show progress, percentage and byte totals, and can be cancelled.
What's new in this version opens the current version's summary in a separate small window.
Update manifests require a valid publisher signature, and downloads are verified with SHA-256.
For protected Program Files installations, setup installs an on-demand update service after the first administrator approval.
Subsequent updates normally require no further approval. The service exits after its task and is removed on uninstall.
Writable custom installation locations, such as Desktop, update application files without repeating administrator approval.
They preserve the uninstaller, history and backups and do not add portable-only Markdown documents.
Unwritable locations or an unavailable Program Files service use the installer with authorization; manually running setup also requires administrator permission.
Updates restart as the original user, with rollback attempted if file replacement fails. Downloads can be cancelled. Checking for updates does not scan or clean files.
Updates require a network connection and may require Windows permission approval.
