# 常用软件内置规则

联网核对日期：2026-10-27。规则使用 Windows 标准用户文件夹、环境变量与版本目录匹配，适用于不同用户名和安装环境；只检查实际存在的 C 盘目标。修改过缓存存储位置的版本可能无法被内置规则命中，常规扫描可补充扩展规则及未知缓存识别。

默认快速扫描只扫描内置低风险项目并提供简洁清理。媒体重建、离线内容和诊断日志需要常规扫描后的高级自选；Adobe 新增项目和 WPS HTTP 缓存始终先备份。年龄、进程和文件状态均会在删除前再次核对；不清空整个应用资料目录。

| 软件 | 检查范围 | 保护和影响 |
| --- | --- | --- |
| 微信 3.x / 4.x | %APPDATA%\Tencent\WeChat / xwechat 的 radium\web\profiles\* 下独立 Cache、Code Cache、GPUCache；旧版 Log、新版 log、crashinfo / dump 及 BrowsingService 指定日志 | 网页资源重新加载；聊天、附件、收藏、插件和小程序数据保留。日志 / 转储高级自选 |
| QQ | %APPDATA%\QQEX\users\* 的独立网页缓存及 logs | 保留 Cookies、聊天数据库、Tencent Files、nt_qq 与收发附件；不采用社区规则中整目录清空 Tencent Files 的操作。内嵌页面缓存是兼容路径检测，不代表覆盖所有 QQ 版本 |
| VS Code | %APPDATA%\Code 的 CachedExtensionVSIXs、CachedData、Cache、Code Cache、GPUCache、ShaderCache、Dawn 缓存；logs、Crashpad 指定转储 | 保留 User、Backups、workspaceStorage、globalStorage、agentSessionData、设置、扩展本体、聊天及未保存编辑 |

| WPS | %LOCALAPPDATA%\Kingsoft 的指定 cache\http*；WPS Cloud Files\UserData\Default\WebCache\http*；旧日志 | 不扫描文档、云文件本体和备份；离线资源可能需重新下载，默认不选并强制备份 |
| Adobe 共享媒体缓存：Premiere Pro、After Effects、Media Encoder、Audition | %APPDATA%\Adobe\Common\Media Cache / Media Cache Files 中的 .cfa、.pek、.ims、.mcdb、.mpgindex | 确认原始素材仍保留并关闭 Adobe 软件；缓存重建可能耗时，高级自选并备份 |
| Photoshop | 独立 web-cache-temp；UXP\PluginsStorage\PHSP\版本\Shared\EBWebView 下指定网页缓存；旧日志 | 保留 Settings 主目录、画笔、预设、插件、PSD/PSB 和自动恢复 |

| Premiere Pro、After Effects、Audition、Media Encoder、Illustrator、InDesign、Character Animator、Lightroom | 各应用限定日志目录中的旧诊断文件；Lightroom 顶层 .log | 不处理工程、素材、目录数据库、智能预览、恢复文件或未保存工作 |

| 浏览器 / 常用客户端 | Edge、Chrome、Firefox、Brave、Opera、QQ 浏览器、夸克，以及 Teams、Steam、Epic 等已知资源缓存 | 保留登录、密码、Cookie、书签、历史、游戏和存档；不删除整个用户资料目录 |

上述固定目录是兼容检测范围。Tencent 私有格式和应用自定义路径没有统一公开保证；无法证明用途的内容仍由常规扫描归为未知项目供核对。没有把整个 Tencent、Adobe、Kingsoft 或 Code 目录判为垃圾。

本次内置库去除 N.E.K.O、ACLOS、OCS Desktop、完美平台、TapTap 等小众启动器，以及浏览器 Beta / Dev / Canary、Discord 测试渠道和部分重复开发工具分支。Winapp2 来源保留完整社区库，通过常规扫描按检测条件匹配，不进入快速扫描。

## 1.3.0 AppData 扩展

- QQ 新增 Roaming\QQ 独立缓存及 Partitions 分区，保留 QQEX 兼容范围，不扫描 nt_data / nt_qq、auth、账号或聊天存储。
- 浏览器补全 Guest Profile 和带 Preferences 指纹的自定义配置名；覆盖独立 ShaderCache、GrShaderCache 及 Dawn 系列缓存。
- VS Code、Obsidian、Postman、Notion、GitHub Desktop、Figma 等补全多配置和分区缓存；新增 Slack、Zoom、ChatGPT、Codex、Typora 的兼容缓存路径及明确的旧诊断范围。程序版本改变或自定义目录时仍可能无法命中。
- Teams、小组件及新版 Outlook 只处理指定包中 EBWebView 的独立资源缓存，支持 WV2Profile_*；不清理邮件数据库、账户或整个 LocalCache / LocalState。公共 WebView2 运行时存在时采取保守运行保护。
- Discord、Spotify、网易云音乐、QQ 音乐新增的低风险项只覆盖界面代码 / GPU 编译缓存，不包括下载音频、收藏、聊天图片或附件。媒体缓存保留原高级自选策略。
- 缩略图仅处理 Explorer 的旧 thumbcache_*.db，原图和文档不在规则范围；NVIDIA 扩展 LocalLow / PerDriverVersion 兼容路径并继续保留近期文件。
- 常规扫描补充 LocalLow 和更深的应用缓存发现；身份、令牌、会话和离线存储排除，未知缓存始终默认不选并先备份。

新增范围依据 [Chromium 磁盘缓存设计](https://www.chromium.org/developers/design-documents/network-stack/disk-cache/)、[Electron 会话 API](https://www.electronjs.org/docs/latest/api/session)、[WebView2 用户数据说明](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/user-data-folder)、[Windows 应用数据说明](https://learn.microsoft.com/en-us/windows/apps/design/app-settings/store-and-retrieve-app-data) 和 [NVIDIA 缓存说明](https://nvidia.custhelp.com/app/answers/detail/a_id/5735/~/deleting-nvidia-shader-cache-files) 核对。应用私有路径结合本机只读目录核对与 Winapp2 兼容规则；来源文档不对 Clarity 的清理结果作保证。
