# 澄净 Clarity 版本历史

[简体中文](版本历史.md) | [English](../CHANGELOG.md)

| 版本 | 主要修改 |
| --- | --- |
| 1.2.1 | 新增批量目录索引扫描，默认启用 Winapp2；重做轻盈清透外观与独立下拉菜单，优化设置页面按需加载。 |
| 1.2.0 | 新增本地扫描缓存与统一扫描会话，减少重复识别、重叠目录读取和进度刷新开销。 |
| 1.1.1 | 新增液态玻璃（Beta）样式，优化磁盘占用展示并统一页面切换动画。 |
| 1.1.0 | 新增可叠加管理的 JSON 规则包、只读预览及文件名/保留期/大小条件；支持 Winapp2 与 JSON 同时启用。 |
| 1.0.6 | 新增按需更新服务与发布者签名校验；扩展简洁清理中的低风险缓存与旧诊断资料。 |
| 1.0.5 | 新增深浅色及跟随系统主题、窗口动画、未完成清理列表与自选关闭休眠；优化清理收尾和 Windows 磁盘清理。 |
| 1.0.0 | 修复规则打包引发的特定误报，加强规则完整性校验、软件更新与备份处理保护。 |
| beta0.20 | 新增软件在线更新和清理记录自动保存，完善备份恢复与规则管理。 |
| beta0.15 | 修复范围卡片点击，新增启动动画与顶部短暂提示；采用 MIT 许可并补充软件使用条款。 |
| beta0.14 | 设置、关于与使用说明改为主窗口内导航；统一标题栏，新增交互动画并提升易读性。 |
| beta0.13 | 新增英文界面与语言设置、关于页及管理员重启提示；提供中英双语 TXT 使用说明。 |
| beta0.12 | 重整设置与备份入口，集中管理文件和注册表恢复；规则来源修改保存后生效。 |
| beta0.11 | 新增安装版，支持自选安装目录、升级和卸载。 |
| beta0.10 | 默认快速扫描；优化内置规则，扩充微信、QQ、Adobe、VS Code、WPS 等常用软件缓存清理。 |
| beta0.09 | 新增快速与常规扫描，优化高级自选和风险确认，加入清理结果页。 |
| beta0.08 | 完善备份恢复，成功恢复后自动清除对应备份；独立选择 Windows 磁盘清理。 |
| beta0.07 | 增加未知缓存识别、风险项目自选删除和可选 Windows 磁盘清理。 |
| beta0.06 | 接入 Winapp2.ini 规则库，支持导入、更新及受限文件清理。 |
| beta0.05 | 新增应用发现、外部规则更新与导入、文件备份恢复。 |
| beta0.04 | 修复重新扫描流程，返回准备页并由用户手动开始。 |
| beta0.03 | 扩展内置清理规则，加入分层分类和受限注册表清理。 |
| beta0.02 | 改为手动开始扫描，扩展清理范围并优化界面。 |
| beta0.01 | 首个便携式 C 盘清理版本，提供垃圾扫描、简洁清理和高级自选。 |
