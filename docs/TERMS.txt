4. 扫描与清理
打开软件不会自动扫描。快速扫描检查内置低风险规则；常规扫描还包含应用发现、外部规则与未知缓存识别。
扫描用于列出候选文件，不能保证每个软件、每个缓存或每台电脑的识别都准确。
开始清理前，请核对扫描范围、路径、说明和风险。缓存删除后可能需要重新生成或下载。
高级自选可以处理原本保留的个人资料、近期文件或未知缓存，可能影响登录状态、配置、历史及离线资料。
风险项目需要单独确认。文件占用、权限不足或扫描后发生变化时，软件可能跳过对应项目。

5. 备份、恢复与系统清理
默认先备份。未知缓存、社区规则和风险删除始终先备份。
文件备份仅支持同一电脑及 Windows 账户恢复，不覆盖已有文件；校验成功的恢复副本会从备份中清除。
清空备份、永久删除及 Windows 自带磁盘清理可能无法恢复；系统磁盘清理不经过 Clarity 的文件备份。
备份可能受磁盘故障、空间不足、权限或安全软件拦截影响。重要资料应另行备份，不能仅依赖 Clarity 的恢复功能。
管理员模式不能保证解决文件占用或安全软件拦截，重启后仍需手动扫描。

6. 规则、隐私与风险
规则更新会下载规则文件，不上传应用列表、路径或扫描结果。外部规则应从可信来源获取。
设置、日志和备份保存在本机，可能包含路径、应用信息或被备份的个人资料；分享前请自行检查。

4. Scanning and cleanup
Opening Clarity does not start scanning. Quick scan checks built-in low-risk rules. Regular scan adds application discovery, external rules, and unknown-cache detection.
Scan results are candidates; accurate identification of every application, cache, or computer is not guaranteed.
Review scopes, paths, explanations, and risks before cleaning. Deleted caches may need rebuilding or downloads.
Advanced selection can remove retained personal data, recent files, or unknown caches, potentially affecting sign-in state, configuration, history, and offline content.
Risk items require confirmation. Locked, inaccessible, or changed files may be skipped.

5. Backups, restoration, and Windows cleanup
Backup-first cleanup is the default. Unknown caches, community rules, and risk deletions always require backups.
File restoration requires the same computer and Windows account, preserves existing files, and removes successfully verified restored copies from the backup.
Backup purging, permanent deletion, and Windows Disk Cleanup may be irreversible. Windows cleanup bypasses Clarity's file backups.
Disk failures, insufficient space, permissions, or security software can prevent backups. Back up important data separately rather than relying solely on Clarity restoration.
Administrator mode may not resolve locked files or antivirus blocks. Restart still requires manual scanning.

6. Rules, privacy, and risks
Rule updates download rule files without uploading application inventories, paths, or scan results. Obtain external rules from trusted sources.
Local settings, logs, and backups may contain paths, application information, or personal backup data. Review them before sharing.
