# Clarity 内置清理规则一览

当前版本 1.0.5，包含 146 条内置规则，其中 28 条符合快速扫描条件。容量需满足路径存在、保留期、软件退出与文件状态检查。默认快速扫描；常规扫描追加应用发现、Winapp2 / JSON 和未知缓存识别。

Clarity 不扫描 Windows 系统目录。Windows 磁盘清理是清理按钮旁的独立可选操作。休眠文件位于系统垃圾中，仅供高级模式自选；通过 Windows 命令关闭休眠与快速启动，不直接删除系统文件，也不经过文件备份。
