# 澄净 · C 盘清理 beta0.09 — by CraZyX

[简体中文](README.md) | [English](README.en.md)


澄净是一款 Windows 便携式 C 盘清理工具，结合应用识别、内置规则、Winapp2 规则库与未知缓存识别，查找系统垃圾和软件缓存。支持常规与快速扫描，提供低风险项目一键清理和高级自选两种方式，清理项目附带详细说明，选中风险项目时提示确认。

默认先备份再清理，支持备份恢复、规则更新和离线导入，也可按需运行 Windows 自带磁盘清理。无需安装，可在不同电脑上使用。

## 开始使用

1. 解压便携包，运行 Clarity.exe，保留 Clarity.exe.config。中文名称为“澄净”。
2. 选择扫描模式及分类。默认“常规扫描”保留原有应用发现、规则匹配与未知缓存识别；“快速扫描”只检查内置的一键清理规则，跳过扩展规则、应用指纹及复杂资料，扫描后仅提供简洁清理。
3. 点击唯一的“开始扫描”。常规扫描先发现应用，文件扫描按已完成规则显示百分比及文件数。
4. 常规扫描完成后出现简洁与高级清理；快速扫描只有简洁清理。顶部显示可处理总量，简洁菜单下显示一键条件总量。
5. 分类 → 软件/浏览器 → 项目可分层展开。未知缓存集中在“软件缓存 → 软件名称 → 未知缓存”三级菜单，继续展开查看具体项目。分类勾选联动子项，半选显示横线，可搜索、筛选、仅选当前列表或只选低风险。
6. 点击项目“说明”查看用途、影响、保留期、路径与应用指纹依据；说明按需显示。
7. 底部默认“先备份清理（可恢复）”。备份至其他盘时可释放 C 盘对应空间；备份在 C 盘时，清空备份后才释放对应空间。低风险一键清理直接执行；选中未知缓存、社区规则、个人资料、注册表或 Windows 系统清理等风险项目时弹出确认。社区、未知缓存及风险删除始终先备份。
8. 点击“重新扫描”返回“准备清理 C 盘”页，保留分类选择；再次手动点击“开始扫描”才执行，没有独立的“扫描范围”入口。
9. 清理结束显示结果页，展示文件估算释放量、备份及跳过/失败情况；点击“完成”返回初始准备页，不自动扫描。
10. 系统目录权限不足时使用“管理员模式”，再手动扫描。

## 新增应用发现与规则库

“应用与规则”入口提供规则更新、已发现应用、便携目录、备份恢复。

在“已发现应用”中选中应用后，可点击“打开应用文件位置”定位程序；程序不存在时尝试打开安装目录，无法确认路径时按钮禁用。此操作只打开资源管理器，不启动应用。

应用发现读取当前用户/系统的卸载项、App Paths、开始菜单、运行进程与服务注册信息，记录应用名、发行商、安装目录及程序路径；检查可执行文件版本、产品名、公司名与数字签名。仅读取文件，不运行发现的程序，不修改安装信息、服务或快捷方式。

发现记录不等于每个应用都已完整识别。缺失路径、权限不足、版本差异和遍历上限会导致遗漏。签名状态明确显示“验证通过”“未验证”或“无可核验程序”；未验证不被冒充为可信签名。版本与产品文字本身也不等于签名认证。

包含 213 条内置基础规则，Windows 磁盘清理作为独立可选动作。默认扩展来源改为用户指定的 Winapp2.ini：随程序内置 260915 版、4,068 条原始定义，启动不联网、不扫描即可离线使用。也可在规则来源中切换到原有 15 条签名 JSON 扩展。实际匹配后的规则数随本机应用、目录和启发式选项变化，不代表固定发现项目数。

Winapp2 使用逐行解析，保留重复和编号指令，支持 OR 检测、常用 SpecialDetect、DetectOS、文件通配模式、递归与排除项。采用安全适配：支持的社区文件项目默认不勾选，不进入一键清理，至少保留 14 天，始终备份；REMOVESELF 保留目录，仅清空允许的文件。RegKey 解析、展示但不执行任意社区注册表删除。普通候选保留密码、Cookie、会话、配置和数据库；存在明确文件目标的保留内容可以另行风险自选。系统核心、显式排除范围与未支持指令仍保留。

本次快照有 14,121 条文件指令，其中 3,839 条可适配为受限制的文件规则；其余 10,282 条文件指令与 3,677 条社区注册表指令保留。这个数量表示格式及范围可适配，不表示本机存在这些目录或可释放相同数量的数据。真实目录还受 C 盘、文件类型、年龄、占用、排除和路径复核约束。

在规则页面添加便携或自定义安装目录，下次手动扫描会检查该目录中有限深度的程序，以及匹配规则中的缓存子目录。支持环境变量、应用安装目录/程序目录/便携根目录、逐层通配符、文件名正则、排除目录/名称及文件类型。仅清理 C 盘；其他盘程序指纹可用于定位其 C 盘用户缓存。

外部规则全部只供高级自选，不覆盖内置一键规则，不执行脚本、任意注册表动作或任意目录递归删除。详细格式见“规则库维护.md”。

## 启发式扫描

常规扫描保留此功能，在有限范围的应用资料目录和明确选择的便携目录中寻找 Cache、GPUCache、Code Cache、Logs、Temp 等特征目录。读取目录全部文件，包括无扩展名、二进制和嵌套内容；普通候选保留最近 1 天及个人资料。快速扫描跳过未知缓存识别。

文档/数据库文件头、敏感名称和最近修改的内容会分为“保留内容自选删除”，默认不选并标红风险，始终先备份。普通未知缓存也不能证明可重建，标记“疑似 · 需核对”，不进入一键清理。项目说明显示已读取数量、普通/保留候选、无法读取和链接/只读等信息；计划容量只统计所选候选。

应用指纹、路径惯例和启发式都是证据，不保证识别所有软件与缓存。自定义目录、未知版本、超过上限或无法确认的内容可能保留或遗漏。

## 风险、备份和容量

| 标记 | 处理方式 |
| --- | --- |
| 青绿色：低风险 | 已知可重建缓存，已过保留期且相关程序未运行；可纳入一键清理 |
| 琥珀色：需确认 / 含需确认项 | 媒体、离线网页、编译、诊断、更新备份或扩展规则；默认不选 |
| 琥珀色：疑似 · 需核对 | 启发式结果；仅高级自选，始终先备份 |
| 琥珀色：社区 · 先备份 / 含社区项 | Winapp2 缓存与日志的安全适配；默认不选，不进入一键清理，始终备份 |
| 粉色：使用痕迹 | 最近访问入口、运行与搜索历史；默认不选 |
| 红色：风险删除 · 先备份 | 原本保留的近期、个人、更新/安装备份等文件可高级自选，确认后强制备份再删除 |
| 红色：系统清理 · 不可恢复 | 可选调用 Windows 清理 C 盘，系统删除不经过澄净备份 |
| 蓝色：保留 | 核心系统保护、使用中或无可执行目标的说明项；展示具体原因和官方处理入口 |

顶部总量含需要确认的候选；简洁菜单量只计入一键条件。底部容量为当前模式实际计划处理的原文件量。低风险缓存仍可能造成首次加载或重新下载变慢，离线使用应自行保留。

默认备份位置优先选有可用空间的其他本地固定磁盘，通常是 D:\ClearSpaceBackups；没有其他盘则使用 %LOCALAPPDATA%\ClearSpace\FileBackups。可在“应用与规则 → 备份与恢复”修改位置。备份目录无权限、磁盘不足或备份/索引写入失败时保留原文件；不存在不备份直接删除的自动降级。

从经过复核的原文件句柄复制备份，写入内容与可恢复索引并刷新后才删除原文件；删除前仍复核位置、身份、大小、修改时间与使用情况。索引用本账户 DPAPI 保护，备份目录限制为本账户、管理员与 SYSTEM；内容附 SHA-256。

底部清理选项旁提供“打开备份位置”，优先打开最近一次仍存在的备份批次；该批次已清除时打开配置的备份根目录。“应用与规则 → 备份与恢复”也提供“打开备份位置”。

“恢复文件备份”选择该批 files.csbackup。只支持本机、本账户；先验证索引与备份内容，已有文件不会被覆盖。恢复权限不足的系统文件可能需要管理员身份。成功恢复并校验的文件会自动清除对应备份；全部完成后清除索引和空批次目录。原文件冲突、失败、损坏及未恢复的备份继续保留，可再次恢复；不会删除备份根目录或批次内的其他文件。仍可用“清空所选备份”明确放弃该批未恢复备份。

同盘备份不会被计入估算净释放量；跨盘或永久删除的估算仍可能受压缩、稀疏文件和后台活动影响。普通项目选择永久删除后不进入回收站，不能从本软件恢复；强制备份项目仍可按备份恢复。停止任务只停止后续处理，不回滚已经完成的清理。

## 云更新与离线导入

“应用与规则 → 规则更新”默认选中 Winapp2.ini，已配置用户提供的官方仓库地址：https://raw.githubusercontent.com/MoscaDotTo/Winapp2/master/Winapp2.ini。点击“检查更新”下载并检查格式；可导入本地 .ini、导出原始规则、查看兼容报告和回退上一版。每 7 天自动检查为可选设置，默认关闭，始终不自动扫描或清理。

Winapp2 地址固定；签名 JSON 地址独立保存，默认空，支持填写 HTTPS 地址或保存为空。切换来源保留 JSON 编辑内容，不会将 Winapp2 地址带入 JSON。

Winapp2 为未签名社区文件，只从上述固定 HTTPS 地址下载，拒绝重定向、无效证书、超过 5 MB 的包、格式错误与日期版本降级；失败保留当前库。格式检查与 SHA-256 不等于发布者签名，界面不会宣称社区包签名已验证。它不会继承 Default 或节名星号来自动勾选项目。

切换到“签名 JSON · 自定义规则”后仍执行原来的签名策略：云端只接受内置发布者签名的包，拒绝 HTTP、重定向、无效证书、未签名内容、过大包与自动降级；此来源的地址仍需自行配置。本地 JSON 可确认导入，未签名来源醒目标记。

更新只获取规则文件，不上传应用列表、文件路径或扫描结果。自动更新不会触发自动扫描或清理。配置、更新缓存和清理日志位于 %LOCALAPPDATA%\ClearSpace。

便携包包含原始 Winapp2.ini、Winapp2-License.md、Winapp2-使用说明.md，以及原有 JSON 示例与编辑模板。INI 使用“本地导入”应用，直接编辑包内副本不覆盖已缓存的规则。原始 Winapp2 数据库属于 Winapp2 项目，按 CC-BY-SA-4.0 分发，内容未修改；本软件实现独立的安全适配器。JSON 发布步骤见“规则库维护.md”；发布私钥不包含在任何交付 ZIP 中。

## 注册表与其他保护

注册表仍只限高级自选，默认不选，按条数单独显示，不计入可释放 GB。App Paths 要求程序及其目录均可证明缺失；卸载残留排除 MSI、Microsoft、系统组件和复杂项。删除前保存带类型的完整值备份并复核；备份失败不删除。顶部提供注册表备份恢复，现有项不覆盖。

不直接删除 Windows 组件库、Installer、DriverStore、Recovery 或还原点；Windows Update、传递优化、Windows.old 交给系统功能。JetBrains 保留 Local History；uv 缓存首选官方命令；如高级风险自选，则必须关闭 uv 并先备份。普通候选保护个人数据，高级风险自选可能删除个人资料，弹窗会逐项提示后果。

只删除明确允许的文件，保留目录。跳过链接、硬链接、云占位、只读、权限异常或使用中的文件；普通候选保留近期修改内容，只有明确风险自选可以解除年龄保留；扫描后变化的文件保留。配置目录、当前备份目录和包含 files.csbackup 索引的备份批次目录自动排除，删除前再核对。不关闭程序，不更改原文件权限。

日志和备份包含本地资料，请自行妥善保存。程序支持 Windows 10/11 和 .NET Framework 4.8，无须 Python、Node.js 或 SDK；AnyCPU，实际验证系统为 Windows x64，其他硬件未逐一实测。程序未做代码签名，规则签名用于规则来源认证；附 SHA-256 和完整构建源码。

## Windows 磁盘清理（可选）

在底部清理按钮上方勾选独立的“运行 Windows 磁盘清理”，简洁与高级模式都可选。默认不选，分类列表不再显示此动作；只有明确勾选才会追加运行。风险弹窗明确提示它可能永久清空 C 盘回收站和系统默认临时资料，无法通过澄净备份恢复；容量由 Windows 计算，不计入扫描或释放估算。

确认后调用系统目录下的 cleanmgr.exe /d C /verylowdisk，按 Windows 默认项目自动处理 C 盘，无需进入系统选择界面，结束后系统工具自行退出。界面等待并显示系统处理状态；停止后续文件清理时，已开始的 Windows 系统操作仍等待结束，不强行终止。缺失工具或失败会显示结果，不自动改用其他盘或修改系统清理配置。

采用微软文档的 /d 与 /verylowdisk；不使用忽略 /d 并遍历全部磁盘的 /sagerun。默认项目随 Windows 版本和系统设置变化，不承诺强制删除 Windows.old 或所有更新文件。

参考：[微软 cleanmgr 参数说明](https://learn.microsoft.com/windows-server/administration/windows-commands/cleanmgr)。

## beta 版本规则

软件显示、EXE 产品版本、更新请求标识与交付包名统一使用 beta0.xx，当前为 beta0.09；每次发布递增，至少保留两位编号。Windows 数值文件版本对应 0.9.0.0。英文程序文件名为 Clarity.exe，中文为“澄净”。唯一构建来源是 version.json，build.ps1 自动生成版本代码；历史对应见“版本历史.md”。Winapp2 的日期版本及 JSON 规则库版本独立管理。
