# 澄净 · C 盘清理 beta0.03 — by CraZyX

便携式 Windows 桌面程序，采用深色界面与 #39C5BB 青绿色重点色。启动不扫描；点击唯一的“开始扫描”后检查所选分类，扫描完成后才显示简洁与高级清理。程序本地运行，无联网上传、服务或驱动。

## 使用

1. 解压便携包，双击 ClearSpace.exe。保留同目录的 ClearSpace.exe.config。
2. 点击分类卡片或勾选框选择范围，再点击“开始扫描”。扫描不会删除文件。
3. 扫描时查看顶部已发现容量、正在检查的内容和显著的进度条。百分比按已完成规则计算；同时显示规则数、已检查文件数。不同规则工作量不同，百分比不表示剩余时间。
4. 扫描完成后选择“简洁 · 一键清理”或“高级 · 自选清理”。简洁菜单下直接显示符合一键条件的总容量。
5. 高级结果按分类 → 软件/浏览器 → 缓存项目展开。分类或软件的复选框联动当前列表内可处理的子项；半选用横线表示。文件项目可点击整行切换勾选。保留项不可勾选。
6. 可搜索软件或项目、按风险筛选；“仅选当前列表”会替换原有勾选，“只选低风险”会替换为推荐项，“清空”取消全部勾选。筛选外仍已勾选的项目会在底部醒目提示。
7. 点击项目的“说明”查看用途、清理影响、保留期和路径。说明默认折叠，减少界面文字。
8. 检查底部计划处理的容量/注册表条数后执行清理。高级模式会再次列出需确认内容。完成后可导出逐项记录。
9. “扫描范围”可返回分类选择页；“重新扫描”更新结果。系统目录权限不足时，可使用“管理员模式”再手动扫描。

## 风险与容量

| 标记 | 处理方式 |
| --- | --- |
| 青绿色：低风险 | 已知的可重建缓存、已过保留期、相关程序未运行；可纳入一键清理 |
| 琥珀色：需确认 / 含需确认项 | 可能影响离线资源、编译、诊断或更新备份；默认不勾选，高级自选 |
| 粉色：使用痕迹 | 最近访问入口、运行命令或搜索历史；默认不勾选 |
| 蓝色：保留 | 显示“不会删除”，包括受保护内容与使用中的缓存 |

顶部大字“可处理垃圾”包含当前符合条件的文件，含需确认项目。简洁菜单容量只累计符合一键清理条件的文件。底部容量是当前模式实际计划处理的内容。文件占用是估算值，不保证等于实际释放空间。

低风险缓存清理仍可能使首次加载、编译或下载变慢。注册表以条数单独显示，不计入可释放 GB；清理注册表不承诺提高性能。

## 注册表清理与恢复

注册表现在支持实际处理，仅限高级模式，默认不选。App Paths 要求简单叶子项、程序文件及其目录都能确认已不存在。卸载残留要求安装目录及卸载程序目录均能确认不存在，排除 MSI 产品、系统组件、Microsoft 项和带子项的复杂记录。失效注册记录保留最近 7 天内改动的项。访问异常、网络路径与其他盘路径保留。

运行命令及资源管理器搜索历史是可选的使用痕迹清理，与失效安装注册记录分开显示。

删除前先保存带类型的完整值备份，并校验写入成功；备份失败则不删除。删除前再次核对内容、修改时间与目标路径。程序只删除白名单内明确选择的叶子键，不扫描或处理任意注册表分支。

备份位置：%LOCALAPPDATA%\ClearSpace\RegistryBackups。点击顶部“恢复注册表备份”，选择本软件生成的 JSON。恢复仅适用于本机、本账户；现有项不会被覆盖。HKLM 项可能需要管理员权限。备份可恢复保存的注册表值，不等于系统还原点。

## 文件保护

只处理明确允许的目录、文件类型或单个文件。跳过链接、硬链接、云端占位、只读、近期修改、无法读取或正在使用的文件。删除前再次核对真实位置、文件身份、大小与修改时间；变化的文件保留。相关程序启动后保留后续文件，不关闭程序、不更改权限。

文件为永久删除，不进入回收站。停止任务只会停止后续处理，已完成的文件删除不能回滚。只删除符合规则的文件，保留空目录。

不清空回收站，不删除个人文档、下载、聊天数据库、密码、Cookie、书签、软件设置、已安装扩展/依赖或未保存文件备份。Recent 只处理顶层 .lnk；失效快捷方式删除前再次核对目标，不处理网络、其他盘或无法确认的目标。

JetBrains 仅处理明确的 caches/index 与旧日志目录，保留 Local History。uv 缓存按其官方要求使用 uv 自身清理命令，本程序仅展示占用。Windows Update、传递优化、Windows.old 交给 Windows 自带存储功能；不直接处理组件库、Installer、DriverStore、Recovery 或还原点。

## 跨电脑与验证

支持 Windows 10 / Windows 11，需要 .NET Framework 4.8 或更高版本。无需 Python、Node.js 或额外 SDK。AnyCPU，实际验证环境为 Windows x64，其他硬件未实测。程序使用当前用户及系统路径，不绑定用户名；默认仅检查 C 盘，没有 C 盘时使用 Windows 所在盘，不处理已迁移到其他盘的缓存。

日志位置：%LOCALAPPDATA%\ClearSpace\Logs。日志与注册表备份包含本地路径及相关记录，请按个人资料保存。程序未做代码签名，附有 SHA-256 和可构建源码。

已完成 36 项文件保护检查、23 项注册表/新增规则检查及 26 项界面操作检查，共 85 项。删除测试仅作用于新建的工作区模拟文件及随机 GUID 命名的 HKCU 临时测试分支。真实缓存和真实注册表候选未被清理。已检查实际 WPF 启动、扫描、结果、注册表与小窗口渲染。

~~~powershell
.\build.ps1 -OutputDirectory .\dist
~~~

~~~powershell
.\dist\ClearSpace.exe --self-test .\verification\files
.\dist\ClearSpace.exe --v2-self-test .\verification\registry
.\dist\ClearSpace.exe --ui-self-test .\verification\ui
~~~

.\dist\ClearSpace.exe --scan-report .\scan-report.json
~~~
