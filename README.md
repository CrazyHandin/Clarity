# Clarity

[简体中文](README.md) | [English](README.en.md)

澄净是一款 Windows C 盘清理工具，提供安装版与便携版，支持系统垃圾与软件缓存识别、低风险项目一键清理、高级自选及备份恢复。

[下载最新版](https://github.com/CrazyHandin/Clarity/releases/latest) · [历史版本](https://github.com/CrazyHandin/Clarity/releases) · [更新记录](docs/版本历史.md)

## 功能特色

- **常用软件清理**：覆盖 Windows、微信、QQ、浏览器、Adobe、VS Code、WPS 等缓存与日志。
- **主题切换**：支持深浅色与跟随 Windows，主页可快速切换。
- **清晰的清理选择**：按分类和软件分层展示，支持搜索、筛选、批量勾选；项目附用途、影响和风险说明。
- **可扩展规则**：Winapp2 与 JSON 可同时启用，支持批量导入多个 JSON 文件并独立启停、升级和回退；按应用指纹、文件名、保留期及大小匹配，并可只读预览。
- **备份与恢复**：默认先备份，可打开备份位置；恢复校验成功后自动清除对应备份。
- **记录与更新**：清理记录自动保存，可在设置中直接打开；启动时检查 GitHub 新版本，支持安装版与便携版在线更新。

从 1.0.5 或更早版本升级到 1.0.6，请从下载页手动安装一次；之后可继续使用在线更新。

## 使用方法

需要 **Windows 10/11 与 .NET Framework 4.8**。

在 **设置与备份 → 常规设置** 切换简体中文或 English，选择会自动保存。软件包中的 TXT 使用说明先列中文，英文位于文档末尾。

1. 下载 `setup.exe` 安装包并安装，或完整解压便携包运行 `Clarity.exe`，保留同目录的 `Clarity.exe.config` 和 `rules` 文件夹。
2. 选择扫描模式，点击 **开始扫描**。打开软件不会自动扫描。
3. 查看结果后清理；选中风险项目时会弹窗确认。清理结束可查看未完成项目及原因，点击 **完成** 返回初始界面。

| 扫描模式 | 扫描范围 | 清理方式 |
| --- | --- | --- |
| 快速扫描（默认） | 内置的一键清理规则，跳过复杂识别 | 简洁清理 |
| 常规扫描 | 内置规则、应用发现、外部规则与未知缓存 | 简洁清理 / 高级自选 |

管理员模式位于 **设置与备份 → 常规设置**，普通权限下清理失败或权限不足时也会询问是否重启；提权后仍需手动扫描。“关于 Clarity”集中展示版本与开发者信息。

设置、关于与内置使用说明均在主窗口内切换，返回清理保留扫描结果及勾选状态。关于页提供版本信息、软件更新和第三方声明。

在“关于”中点击“检查软件更新”，发现新版本时可在弹窗中查看说明、下载并更新；设置和关于入口会显示红点。“本版更新内容”按钮用于查看当前版本概括。

安装到受保护的 Program Files 目录时，安装包会配置按需更新服务。桌面等当前账户可写的自定义目录会直接更新程序文件，保留卸载程序、记录和备份。这两种方式的后续更新无需重复授权；目录无写入权限或更新服务未就绪时，使用需要授权的安装器。更新清单验证发布者签名，软件包验证 SHA-256。手动运行安装包仍需管理员权限。

简洁清理只处理符合一键条件的低风险项目；高级清理可逐项选择并查看说明。未知缓存和社区规则默认不选，仅供高级自选，始终先备份。

## 备份与注意事项

默认备份目录为 **ClarityBackups**，优先放在其他本地磁盘，可在“设置与备份 → 备份与恢复”修改。备份位于 C 盘时，对应空间需清空备份后才释放。

恢复时选择备份批次的 `files.csbackup`，仅支持本机、本账户，不覆盖已有文件。成功恢复的备份自动清除，冲突或失败的内容继续保留。

低风险缓存清理也可能导致重新下载或首次加载变慢。高级风险删除可能涉及个人资料，请核对说明。占用、权限不足或扫描后变化的文件会跳过。

**Windows 磁盘清理**是独立可选项，默认关闭；启用后自动处理 C 盘并在结束时退出，其删除不经过澄净备份，可能无法恢复。

## 规则与隐私

在“设置与备份 → 规则管理”分别管理 Winapp2 和 JSON。“JSON 规则库”可一次导入多个 Schema 1 / 2 JSON 文件，默认关闭，支持只读预览、启停、升级与回退。规则变更在下次常规扫描生效，重叠候选文件只计算和处理一次。更新只获取规则文件，不上传应用列表、文件路径或扫描结果，也不会自动扫描或清理。

Winapp2 规则数据库按 **CC BY-SA 4.0** 分发，详见[第三方说明](THIRD_PARTY_NOTICES.md)。

## 构建与文档

使用 C# / WPF 和 .NET Framework 编译器构建：

```powershell
.\build.ps1 -OutputDirectory .\dist
```

源码目录：`src/`（界面、清理、规则、识别与恢复）、`tests/`（隔离测试）、`assets/`（图标与配置）、`rules/`（规则数据）、`installer/`（安装配置）、`scripts/`（辅助工具）、`docs/`（技术文档）。构建与打包入口保留在根目录，安装包构建与发布见[构建说明](docs/BUILD.md)。
