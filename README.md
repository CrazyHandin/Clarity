# 澄净 · C 盘清理 beta0.05 — by CraZyX

Windows 便携式 C 盘清理工具，深色界面与 #39C5BB 重点色。启动不会扫描或清理；点击“开始扫描”后先发现应用，再匹配规则与扫描文件。默认先备份清理，支持恢复。

## 开始使用

1. 解压便携包，运行 ClearSpace.exe，保留 ClearSpace.exe.config。
2. 选择分类；需要检查未知缓存时，勾选“深度识别未知缓存（高级自选）”。它默认关闭。
3. 点击唯一的“开始扫描”。应用发现阶段显示正在检查的来源，文件扫描阶段按已完成规则显示百分比及文件数。
4. 扫描完成后才出现简洁与高级清理。顶部大字显示可处理总量；简洁菜单下显示一键条件总量。
5. 分类 → 软件/浏览器 → 项目可分层展开；分类勾选联动子项，半选显示横线。可搜索、按风险筛选、仅选当前列表、只选低风险或清空。
6. 点击项目“说明”查看用途、影响、保留期、路径与应用指纹依据；说明按需显示。
7. 底部默认“先备份清理（可恢复）”。备份至其他盘时可释放 C 盘对应空间；备份在 C 盘时，界面会提示清空备份后才释放空间。永久删除方式需要确认；启发式项目始终先备份。
8. 点击“重新扫描”返回“准备清理 C 盘”页，保留分类选择；再次手动点击“开始扫描”才执行，没有独立的“扫描范围”入口。
9. 系统目录权限不足时使用“管理员模式”，再手动扫描。

## 新增应用发现与规则库

“应用与规则”入口提供规则更新、已发现应用、便携目录、备份恢复。

应用发现读取当前用户/系统的卸载项、App Paths、开始菜单、运行进程与服务注册信息，记录应用名、发行商、安装目录及程序路径；检查可执行文件版本、产品名、公司名与数字签名。仅读取文件，不运行发现的程序，不修改安装信息、服务或快捷方式。

发现记录不等于每个应用都已完整识别。缺失路径、权限不足、版本差异和遍历上限会导致遗漏。签名状态明确显示“验证通过”“未验证”或“无可核验程序”；未验证不被冒充为可信签名。版本与产品文字本身也不等于签名认证。

基础目录保持 213 条保守检查规则；新增 15 条可维护、带应用检测条件的签名扩展规则。实际匹配后的规则数随本机应用、目录和启发式选项变化，不代表固定发现项目数。

在规则页面添加便携或自定义安装目录，下次手动扫描会检查该目录中有限深度的程序，以及匹配规则中的缓存子目录。支持环境变量、应用安装目录/程序目录/便携根目录、逐层通配符、文件名正则、排除目录/名称及文件类型。仅清理 C 盘；其他盘程序指纹可用于定位其 C 盘用户缓存。

外部规则全部只供高级自选，不覆盖内置一键规则，不执行脚本、任意注册表动作或任意目录递归删除。详细格式见“规则库维护.md”。

## 启发式扫描

启用后，在有限范围的应用资料目录和明确选择的便携目录中寻找 Cache、GPUCache、Code Cache、Logs、Temp 等特征目录，仅考虑至少 30 天未改动的 .tmp、.log、.cache、.dmp 文件。

文件头用于保守排除文档、图片、SQLite、ZIP 与程序等内容；排除账号、会话、配置、数据库及敏感子目录。文件头与文件年龄无法证明可重建，因此结果明确标记“疑似 · 需核对”，默认不选，不进入一键清理。显示的容量只计入通过当前条件的候选，不是整个目录占用。

应用指纹、路径惯例和启发式都是证据，不保证识别所有软件与缓存。自定义目录、未知版本、超过上限或无法确认的内容可能保留或遗漏。

## 风险、备份和容量

| 标记 | 处理方式 |
| --- | --- |
| 青绿色：低风险 | 已知可重建缓存，已过保留期且相关程序未运行；可纳入一键清理 |
| 琥珀色：需确认 / 含需确认项 | 媒体、离线网页、编译、诊断、更新备份或扩展规则；默认不选 |
| 琥珀色：疑似 · 需核对 | 启发式结果；仅高级自选，始终先备份 |
| 粉色：使用痕迹 | 最近访问入口、运行与搜索历史；默认不选 |
| 蓝色：保留 | 显示“不会删除”，保护内容与使用中的缓存不可勾选 |

顶部总量含需要确认的候选；简洁菜单量只计入一键条件。底部容量为当前模式实际计划处理的原文件量。低风险缓存仍可能造成首次加载或重新下载变慢，离线使用应自行保留。

默认备份位置优先选有可用空间的其他本地固定磁盘，通常是 D:\ClearSpaceBackups；没有其他盘则使用 %LOCALAPPDATA%\ClearSpace\FileBackups。可在“应用与规则 → 备份与恢复”修改位置。备份目录无权限、磁盘不足或备份/索引写入失败时保留原文件；不存在不备份直接删除的自动降级。

从经过复核的原文件句柄复制备份，写入内容与可恢复索引并刷新后才删除原文件；删除前仍复核位置、身份、大小、修改时间与使用情况。索引用本账户 DPAPI 保护，备份目录限制为本账户、管理员与 SYSTEM；内容附 SHA-256。

“恢复文件备份”选择该批 files.csbackup。只支持本机、本账户；先验证索引与备份内容，已有文件不会被覆盖。恢复权限不足的系统文件可能需要管理员身份。已恢复备份仍保留，可用“清空所选备份”明确删除该批备份文件与索引。

同盘备份不会被计入估算净释放量；跨盘或永久删除的估算仍可能受压缩、稀疏文件和后台活动影响。选择永久删除后不进入回收站，不能从本软件恢复。停止任务只停止后续处理，不回滚已经完成的清理。

## 云更新与离线导入

目前未配置发布地址，没有预设云端服务。软件支持填写真实 HTTPS 规则文件地址、手动检查、可选每 7 天检查一次、签名验证、上一版回退及本地导入。

云端仅接受内置发布者签名的包，拒绝 HTTP、重定向、无效证书、未签名内容、过大包与自动降级。校验失败保留当前规则。未签名本地 JSON 可以确认导入，但醒目标记来源，全部只供高级自选。

更新只获取规则文件，不上传应用列表、文件路径或扫描结果。自动更新不会触发自动扫描或清理。配置、更新缓存和清理日志位于 %LOCALAPPDATA%\ClearSpace。

便携包包含已签名示例与未签名编辑模板。发布步骤见“规则库维护.md”；源码提供 Publish-Rules.ps1、公钥和签名示例。发布私钥留在工作区 publisher-private，不包含在任何交付 ZIP 中。

## 注册表与其他保护

注册表仍只限高级自选，默认不选，按条数单独显示，不计入可释放 GB。App Paths 要求程序及其目录均可证明缺失；卸载残留排除 MSI、Microsoft、系统组件和复杂项。删除前保存带类型的完整值备份并复核；备份失败不删除。顶部提供注册表备份恢复，现有项不覆盖。

不直接删除 Windows 组件库、Installer、DriverStore、Recovery 或还原点；Windows Update、传递优化、Windows.old 交给系统功能。JetBrains 保留 Local History；uv 缓存交给官方命令。保护个人文档、账号、密码、Cookie、书签、设置、聊天数据库和未保存资料。

只删除明确允许的文件，保留目录。跳过链接、硬链接、云占位、只读、近期修改、权限异常或使用中的文件；扫描后变化的文件保留。配置目录、当前备份目录和包含 files.csbackup 索引的备份批次目录自动排除，删除前再核对。不关闭程序，不更改原文件权限。

日志和备份包含本地资料，请自行妥善保存。程序支持 Windows 10/11 和 .NET Framework 4.8，无须 Python、Node.js 或 SDK；AnyCPU，实际验证系统为 Windows x64，其他硬件未逐一实测。程序未做代码签名，规则签名用于规则来源认证；附 SHA-256 和完整构建源码。
